# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

In short: be respectful, assume good faith, and keep discussion focused and
professional. Harassment, personal attacks, or discriminatory language will not
be tolerated. Violations can be reported to the maintainer via the contact
listed in `pyproject.toml`.
